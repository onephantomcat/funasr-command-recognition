# 方案 A: 分离式声纹验证 (SV Source Mix)

## 描述
传统方案（方案 A 之前）：
- 混合音频 (Mix Audio) → P2 TSE 模型（语音增强/目标说话人提取）→ 提取目标音频 (Target Audio)
- 目标音频 → 声纹验证模型 (CAM++) → 相似度得分 → 门控判断

方案 A：
- 混合音频 (Mix Audio) → **直接**送入声纹验证模型 (CAM++) → 相似度得分 → 门控判断
- （注：P2 TSE 仍可用于 ASR 辅助，但不参与声纹验证流程）

## 代码修改
无需修改任何代码。`eval_datasetA.py` 原生支持此功能，通过 CLI 参数控制。

## 如何使用
在运行 `eval_datasetA.py` 时，添加参数 `--sv-source mix`。

```bash
python eval_datasetA.py \
  --root <dataset_path> \
  --sv-source mix \
  # 其他参数...
```

## 状态与结论 (2026-08-20)
- **状态**: 已在 DatasetA 全量上测试，但**未通过**验证。
- **结果**: 闸门 4 实验显示，`--sv-source mix` 在全量数据上的正样本接受率（69.35%）与基线持平，但负样本拒绝率略降，正样本 CER 恶化（+6.5pp）。这说明混合音频中的干扰噪声足以抵消 P2 模型的增强优势，方案 A 失败。
- **结论**: 此方案失败，保留基线。相关代码路径保留以做后续研究。
